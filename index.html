About

I work on memory systems and computer architecture for AI. At Micron, I study memory architectures for large language model training and inference. My doctoral research at Colorado State University explores how reinforcement learning can improve scheduling, routing, and memory management.

I am a PhD student in Computer Engineering at Colorado State University, advised by Prof. Sudeep Pasricha.

01

Research

Memory systems for AI

DRAM and HBM architecture, memory hierarchy, and the performance and cost tradeoffs that shape large-model training and inference.

Learning-based optimization

Reinforcement learning for LLM serving, disaggregated memory, on-chip routing, and adaptive resource management.

Architecture modeling

Simulation and performance analysis across processors, memory, interconnects, and distributed AI systems.
