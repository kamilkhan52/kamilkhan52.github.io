About

I build and study ML systems through workload characterization, performance modeling, and learning-based optimization.

At Micron, I study how large-model training and inference interact with memory systems. My doctoral research at Colorado State University, advised by Prof. Sudeep Pasricha, uses reinforcement learning to improve scheduling and resource management across the stack.

Current work

My current work starts with the workload: model its behavior, identify the system bottleneck, and then search for better scheduling or architecture decisions.

LLM serving systems

Tail-aware design stage

Vidur-RL

Vidur-RL investigates reinforcement-learning schedulers for large-language-model inference. The project asks how a global scheduler can balance queue pressure, cache locality, and replica load while protecting user-facing tail latency. Current work focuses on queue-aware state and bounded per-request rewards, evaluated on P99 end-to-end latency, time to first token, and time per output token against strong scheduling heuristics.

Related systems work

Disaggregated memory for AI

I also study how pooled memory can expand capacity for AI workloads, including KV-cache placement and offloading. CORMEM contributes a learning-based foundation for coordinating network paths and memory endpoints in CXL fabrics.
