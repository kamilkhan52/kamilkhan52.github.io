# Kamil Khan — personal website

A dependency-free personal research website hosted with GitHub Pages.

## Update the site

Edit `index.html` for content or `styles.css` for presentation. Preview locally by opening
`index.html` in a browser, then commit and push to `main`. GitHub Pages publishes the new version
automatically from the repository root.

## Structure

- `index.html` — page content and metadata
- `styles.css` — responsive layout and visual design
- `assets/favicon.svg` — site icon

The live site is <https://kamilkhan52.github.io/>.
